# 我的鋼琴（PWA）

個人使用的 iPhone 虛擬鋼琴網頁 App。用 Safari 打開網址 →「分享 → 加入主畫面」，即可全螢幕、離線使用，不需 Apple 開發者帳號，也不會過期。

## 功能
- Web Audio API + 真實鋼琴取樣（30 個取樣，每小三度一個，其餘以變速移調補齊），全部預先解碼成 AudioBuffer
- 低延遲：觸控用 touchstart 觸發（非 click）、`latencyHint: 'interactive'`、首次觸碰解鎖 AudioContext；iOS 17+ 設定 `navigator.audioSession.type = 'playback'`（可不受靜音開關影響）
- 多指同時按、滑音（手指滑過琴鍵會彈新音）、放開時短淡出；禁止捲動 / 縮放 / 長按選單 / 選取文字
- 八度切換（◀ ▶）、範圍 1–3 個八度、音名標示（無 / CDE / Do Re Mi）、延音踏板、音量
- 回音（殘響）：無回音 / 短（約 1.2 秒）/ 長（約 3.5 秒），ConvolverNode + 程式產生的脈衝響應，切換時以增益平滑淡入淡出，不會有爆音
- 和弦顯示：同時按住 2 個以上的鍵時顯示和弦名稱（支援轉位 / 分數和弦，如 C/E），兩音時顯示音程（如 大三度）
- 所有設定存在 localStorage；Service Worker 快取全部檔案，第一次載入後可離線使用
- 電腦鍵盤：A W S E D F T G Y H U J K O L P ; ' 彈奏，Z / X 換八度，空白鍵 = 延音

## MPC
工具列可切換「鋼琴 / MPC」。MPC 是 4×4 鼓墊加可調拍號的步進循環，速度（BPM）與播放都走同一個 AudioContext，所以切回鋼琴時節奏會繼續。工具列上的「鼓聲繼續 / 鼓聲停止」在兩個畫面都看得到，用來讓鼓循環繼續或停掉。

拍號：2/4、3/4、4/4、5/4、6/4、7/4、5/8、6/8、7/8、9/8、12/8。每步可選 8 分、16 分、32 分音符。BPM 是四分音符速度，換拍號不會把音符加快或放慢。6/8、9/8、12/8 的重音是附點四分音符；5/8 是 3+2、7/8 是 2+2+3。換拍號或音符時，對得上新格子的音留著，對不上的丟掉。

循環長度可以選 1 到 8 小節，新專案預設 2 小節。加一小節會複製最後一小節；刪掉有音符的小節會先問一聲，空的就直接刪。舊存檔沒有小節數時維持原本的 1 小節，不會自動複製成兩小節。下面那一列永遠剛好鋪滿螢幕寬度。可以選擇一次看 1 小節或 2 小節（循環至少要有 2 小節才能看兩格），再用左右箭頭翻頁。開「跟隨」時，播放中的那頁會自己轉過來；循環本身一律整段播放，跟畫面顯示幾小節無關。格子很密時可以按住拖過去連畫或連消。

鼓墊、音軌左邊的色條，以及下面有音符的格子，用同一組莫蘭迪色，一種音色一種顏色。

「節奏」選單可載入內建節奏（搖滾、流行、放克、嘻哈、R&B、迪斯可、雷鬼、巴薩諾瓦、爵士搖擺、華爾滋、六八慢歌、藍調）。會換掉目前的拍號、音符、小節數、速度與音軌；若已經有音符會先詢問。載入後可用「還原」回到載入前。

快速填入作用在目前這條音軌的整段循環。小節首、每拍、反拍、2·4拍、每8分、每16分是「加上」，不會清掉本來就有的音。反拍是每拍正中間；格子對不到正中間（例如 6/8 用八分音符）就沒有這個鍵。2·4拍只給四分拍號。每16分要解析度至少到十六分音符。清除會清空這軌；反轉把有音和沒音對調；複製把第一小節貼到後面每一小節。還原回到按上一個快速鍵之前。按格子改節奏之後，還原就會取消。

音軌模型：一條音軌 = 一種音色的一行步進（最多 8 條，疊在同一條循環上）。每條有自己的套鼓、音色、靜音與音量。鼓墊用來即時打目前這條音軌的套鼓；點步進格寫入這條音軌。套鼓有三組：原聲、電子、打擊。

存檔：
- 「存到此機」把有名稱的專案放進 localStorage，可再載入或刪除。目前編輯也會自動存成草稿。
- 「匯出 JSON」／「匯入」用檔案帶走專案。iPhone 優先走系統分享（存到「檔案」）；JSON 若不能以檔案分享，會改分享文字。
- 「匯出音檔」把整段循環播兩次做成 WAV。iOS 的分享必須在點按當下呼叫，所以要點兩次：先製作，再「點一下分享音檔」。

鼓的聲音全部用 Web Audio 在裝置上合成，沒有額外音檔。

電腦鍵盤在 MPC 模式：`1`–`0`、`q` `w` `e` `r` `t` `y` 打 16 個鼓墊，空白鍵 = 鼓聲繼續／停止。

## 檔案
- `index.html`、`style.css`、`app.js`（鋼琴）、`chord.js`（和弦辨識）、`mpc-logic.js`（節拍與存檔）、`mpc-presets.js`（節奏預設）、`mpc-synth.js`（鼓聲合成）、`mpc.js`（MPC 畫面）、`sw.js`（Service Worker）、`manifest.webmanifest`、`icons/`、`samples/`
- 測試：`node --test tests/chord.test.js tests/mpc.test.js tests/grooves.test.js`
- 無需建置步驟，任何靜態主機都可放（GitHub Pages、Netlify、Cloudflare Pages…）。必須是 HTTPS 才能註冊 Service Worker。

## 更新程式後
修改檔案後請把 `sw.js` 裡的 `CACHE` 版本號加一（目前是 `piano-v7`），手機上重新開啟 App 兩次即可拿到新版。GitHub Pages 由 `main` 分支的根目錄提供，不使用 Actions。
